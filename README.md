# JKAnime para Mangayomi

Fuente comunitaria para Mangayomi que consulta JKAnime.

## Repositorio

Índice de anime:

https://raw.githubusercontent.com/Pirkast85/jkanime-mangayomi/main/anime_index.json

## Estado

- Catálogo: implementado.
- Búsqueda: implementada.
- Ficha y géneros: implementados.
- Episodios: implementados mediante detección de enlaces.
- Vídeo: detección de reproductores/iframes y resolución de MP4/M3U8.

La extensión no aloja ni redistribuye vídeos. JKAnime puede cambiar su HTML, reproductores o protecciones; en ese caso habrá que actualizar el extractor.
